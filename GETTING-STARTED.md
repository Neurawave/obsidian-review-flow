# Getting started

*[Svenska](KOM-IGANG.md)*

You do this once. It takes about ten minutes.

1. **Install Obsidian.** Download it from [obsidian.md/download](https://obsidian.md/download) and install it.
2. **Install GitHub Desktop.** Download it from [desktop.github.com](https://desktop.github.com), open it and sign in with your GitHub account.
3. **Get the documents.** In GitHub Desktop: **File → Clone repository**, pick the documents repository and click **Clone**.
4. **Open them in Obsidian.** Choose **Open folder as vault** and pick the folder you just cloned.
5. **Install Review Flow.** In Obsidian: **Settings → Community plugins**, turn them on, choose **Browse**, find **BRAT**, then **Install** and **Enable**. Then press Cmd/Ctrl+P, choose **BRAT: Add a beta plugin for testing**, paste `Neurawave/obsidian-review-flow` and click **Add plugin**.
6. **Choose the folder.** In **Settings → Review Flow → Folders**, type the folder you edit, for example `qms`.
7. **Follow the Changes panel** on the left. The first time, it helps you install the GitHub tool and sign in. You get a code to paste on GitHub.

Done. From then on, just write and click **Send for approval**.

## If something comes up

- **Mac:** if macOS offers to install the *command line developer tools*, click **Install** and wait until it finishes.
- **Windows:** also install [Git](https://git-scm.com/download/win).
- **The panel is not showing:** open the command palette (Cmd/Ctrl+P) and choose **Review Flow: Show changes**.
- **The panel says images are not included:** click **Fix the setting**.
