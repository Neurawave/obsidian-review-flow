# Getting started

*[Svenska](KOM-IGANG.md)*

1. [Install Obsidian](https://obsidian.md/download) and create a vault.
2. [Install Review Flow](https://community.obsidian.md/plugins/review-flow).

The **Changes** panel then guides you the rest of the way: sign in to GitHub and get the documents.

> Review Flow is waiting to be accepted into Obsidian's community directory. Until then, the link in step 2 does not work. Install it with BRAT instead, see the [README](README.md#installation).
