# Kom igång

*[English](GETTING-STARTED.md)*

1. [Installera Obsidian](https://obsidian.md/download) och skapa ett valv.
2. [Installera Review Flow](https://community.obsidian.md/plugins/review-flow).

Sedan guidar panelen **Ändringar** dig resten av vägen: logga in på GitHub och hämta dokumenten.

> Review Flow väntar på att godkännas i Obsidians katalog. Tills dess fungerar inte länken i steg 2. Installera i stället via BRAT, se [README](README.sv.md#installation).
