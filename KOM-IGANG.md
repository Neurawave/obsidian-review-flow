# Kom igång

*[English](GETTING-STARTED.md)*

Det här gör du en gång. Det tar ungefär tio minuter.

1. **Installera Obsidian.** Ladda ner från [obsidian.md/download](https://obsidian.md/download) och installera.
2. **Installera GitHub Desktop.** Ladda ner från [desktop.github.com](https://desktop.github.com), öppna och logga in med ditt GitHub-konto.
3. **Hämta dokumenten.** I GitHub Desktop: **File → Clone repository**, välj dokumentrepot och klicka på **Clone**.
4. **Öppna dem i Obsidian.** Välj **Open folder as vault** och välj mappen du just hämtade.
5. **Installera Review Flow.** I Obsidian: **Settings → Community plugins**, slå på dem, välj **Browse**, sök efter **BRAT**, **Install** och **Enable**. Tryck sedan Cmd/Ctrl+P, välj **BRAT: Add a beta plugin for testing**, klistra in `Neurawave/obsidian-review-flow` och klicka på **Add plugin**.
6. **Välj mapp.** Under **Settings → Review Flow → Folders**, skriv mappen ni redigerar, till exempel `qms`.
7. **Följ panelen Ändringar** till vänster. Första gången hjälper den dig att installera GitHub-verktyget och logga in. Du får en kod som du klistrar in på GitHub.

Klart. Sedan är det bara att skriva och trycka på **Skicka för godkännande**.

## Om något dyker upp

- **Mac:** frågar macOS om att installera *kommandoradsverktyg*, klicka på **Installera** och vänta tills det är klart.
- **Windows:** installera även [Git](https://git-scm.com/download/win).
- **Panelen syns inte:** öppna kommandopaletten (Cmd/Ctrl+P) och välj **Review Flow: Visa ändringar**.
- **Panelen säger att bilder inte följer med:** klicka på **Rätta inställningen**.
